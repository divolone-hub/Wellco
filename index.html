☁️ Как подключить бесплатное облако

Вариант 1: Firebase Realtime Database (Мгновенная синхронизация)

1. Откройте консоль console.firebase.google.com → создайте проект → раздел Realtime Database.

2. Скопируйте ссылку вида https://ваш-проект-default-rtdb.firebaseio.com/welldent.json и вставьте её в поле URL облачной базы.

Вариант 2: Google Таблицы (Через Google Apps Script)

Создайте пустую Google Таблицу → Расширения → Apps Script, вставьте код ниже и нажмите «Начать развертывание → Веб-приложение (Доступ: Все)»:

function doPost(e) {
  PropertiesService.getScriptProperties().setProperty('DB', e.postData.contents);
  return ContentService.createTextOutput('{"ok":true}').setMimeType(ContentService.MimeType.JSON);
}
function doGet() {
  var db = PropertiesService.getScriptProperties().getProperty('DB') || '{}';
  return ContentService.createTextOutput(db).setMimeType(ContentService.MimeType.JSON);
}
Вариант 3: Telegram-бот (Авто-бэкап в ваш чат)

Укажите токен бота от @BotFather и ваш Chat ID — при нажатии «Выгрузить в облако» бот пришлёт актуальную сводку и резервную копию базы прямо вам в Telegram.

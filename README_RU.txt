WELL DENT — автономная Android-оболочка
=======================================

Что это:
- Android-приложение открывает локальную копию index.html из APK.
- Tailwind и html2pdf скачиваются на этапе облачной сборки и кладутся внутрь APK.
- Основные данные остаются на телефоне через localStorage и IndexedDB.
- Экспорт CSV/JSON/TXT/HTML сохраняется в Загрузки/WELL DENT.
- Импорт CSV и JSON использует системный выбор файла Android.
- Внешние ссылки (например Telegram) открываются отдельным приложением/браузером.

Ограничения:
- Первичная сборка требует интернет в GitHub Actions, чтобы скачать библиотеки и зависимости Android.
- После установки интерфейс и локальная база работают без интернета.
- Облачная синхронизация, Telegram, внешние сайты и прочие сетевые функции требуют интернет.
- Данные хранятся локально на устройстве. Удаление приложения или очистка его данных может удалить базу; регулярно делайте JSON-бэкап.
- Отпечаток пальца из исходного WebAuthn-кода не гарантируется в Android WebView; PIN приложения остаётся доступен.
- Печать/PDF следует проверить на реальном устройстве после сборки.

СБОРКА APK С ТЕЛЕФОНА БЕЗ ANDROID STUDIO
----------------------------------------
1. Создайте новый GitHub-репозиторий (например well-dent-android).
2. Загрузите содержимое этой папки в корень репозитория. Важно: папку .github тоже загрузить.
3. Откройте вкладку Actions в репозитории.
4. Выберите "Build WELL DENT APK" и нажмите Run workflow (или дождитесь завершения запуска после push).
5. После успешной сборки откройте запуск workflow и скачайте артефакт WELL-DENT-offline-APK.
6. Распакуйте скачанный артефакт ZIP и установите app-debug.apk на телефон. Android может попросить разрешить установку из этого источника.

Сборка вручную на компьютере:
- Нужны JDK 17, Android SDK Platform 35 и Gradle 8.7.
- Выполнить: bash scripts/fetch-vendor.sh
- Затем: gradle assembleDebug
- APK: app/build/outputs/apk/debug/app-debug.apk

ПЕРЕД ИСПОЛЬЗОВАНИЕМ
--------------------
Сначала установите APK и проверьте на тестовых данных: создание товара, продажу, приход,
закрытие и повторный запуск, экспорт JSON, импорт JSON, экспорт CSV и PDF. До такой
проверки не переносите в приложение единственную рабочую базу.
